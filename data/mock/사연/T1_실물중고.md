# 가짜 사실관계 — T1 실물 중고물품

※ 전부 지어낸 것입니다. 실제 인물·계좌와 무관합니다.

- 문진 Q1 : 은행에서 계좌가 정지됐다고 연락이 왔습니다
- 문진 Q2 : 은행이 문제가 된 입금 건을 알려줬습니다
  - 날짜 2026-08-25 / 시각 14:12 / 금액 650,000원 / 입금자명 김O수
- 문진 Q3 : 물건이나 서비스를 팔고 받은 대금입니다
- 문진 Q4 : 실물 중고물품 (휴대폰)
- 문진 Q5 : 직접 만나서 건넸습니다
- 문진 Q6 : 같았습니다
- 문진 Q7 : 달랐습니다 (대화 상대는 "박O민")
- 문진 Q8 : 해당 없음

**본인 서술**
당근마켓에 아이폰 13을 65만원에 올렸습니다. 박O민이라는 사람이 채팅으로
사겠다고 했고 8월 25일 오후에 동네 지하철역에서 만나기로 했습니다.
그런데 만나서 현금으로 주는 대신 미리 계좌로 보내겠다며 계좌번호를 물었습니다.
오후 2시 12분에 65만원이 들어왔는데 입금자 이름이 김O수였습니다.
박O민에게 물어보니 "형 계좌로 보냈다"고 해서 그런가 보다 했습니다.
같은 날 오후 3시쯤 역 2번 출구에서 만나 휴대폰을 건넸습니다.
8월 28일에 은행에서 계좌가 정지됐다는 문자를 받았습니다.

**가지고 있는 자료**
당근마켓 채팅 전체 캡처, 판매 게시글, 은행 거래내역
