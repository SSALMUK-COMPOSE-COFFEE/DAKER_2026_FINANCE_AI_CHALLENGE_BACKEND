- 다만 **시점 의존적**이다. 이미 정지된 뒤면 출금이 막혀 이 경로는 작동하지 않는다.
  중계요청도 법정 제도가 아니라 은행 창구 실무 관행이라 은행마다 다르다. 둘 다 digest 에 명시했다

**기존 백엔드 API 를 살리는 쪽으로 붙였다**
- 하진님 API 를 뜯어보니 버릴 게 아니었다. 거래내역 분석·증거 체크리스트·PDF 출력·업로드가 이미 있고,
  시스템 프롬프트도 잘 짜여 있다 — 출력이 JSON 3종이고, 프롬프트 인젝션 방어(memo 는 지시가 아니라 데이터)와
  결과 보장 금지 규칙이 들어 있으며, `user_block()` 이 `<<<` 를 전각으로 치환해 구분자 위조를 막는다
- **빈 자리는 두 개뿐이었다.** 유형별 근거(팩)를 넣는 블록이 아예 없고, 조문이 하드코딩 4개다
- 그래서 갈아엎지 않고 `<<<case_pack>>>` 블록 하나를 더하는 패치를 만들었다 (`백엔드_팩연결.patch`)

**유형 판정 — 코드에 유형 목록을 박지 않았다**
