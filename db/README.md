# db

풀림 코퍼스 데이터베이스. PostgreSQL 18 + pgvector.

## 저장하는 것

기획서 5번의 자체 수집 코퍼스(상담사례·당사자 게시글·보도자료·판례·피해사례·은행 안내 실측)와
2층 검색이 쓰는 청크·임베딩을 담는다.

## 저장하지 않는 것

이용자가 입력한 자유 서술, 업로드 파일, 생성된 소명서는 **저장하지 않는다.**
기획서 4번 운영 3원칙의 '저장하지 않음'에 해당하며, 이용자 데이터용 테이블을 두지 않는 것으로 강제한다.

## 실행

```bash
cd ../deploy && docker compose up -d db
```

초기화 스크립트는 `init/`의 파일명 순서로 최초 기동 시 1회만 실행된다.
스키마를 고쳤으면 볼륨을 지우고 다시 올려야 반영된다.

```bash
docker compose down -v && docker compose up -d db
```

## 임베딩 차원

`document_chunks.embedding`은 1024차원이다. 다른 모델을 쓰면 차원과 HNSW 인덱스를 함께 고쳐야 한다.
